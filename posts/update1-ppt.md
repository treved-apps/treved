# 🌐 The Web Version Has Arrived!

It's finally here. **PrintPriceTool is now available on the web!** 🎉

For a long time, one of the most requested additions to PrintPriceTool has been a version that you can use directly from your browser — and after plenty of work, it's finally ready.

## 💻 PrintPriceTool — now on the web

You can now use PrintPriceTool **without installing anything**. Just open your browser and start calculating.

The web version brings the core PrintPriceTool experience to your computer and other devices, making it easier to quickly calculate printing costs wherever you are.

👉 **Try the Web Version:**  
https://treved.pages.dev/apps/print-price-tool

## 🚧 More improvements are coming

This is only the **beginning for the web version**.

We already have plans for further improvements, new features, and refinements to make the browser experience even better. We'll continue listening to your feedback and improving the web version over time.

So if there's something you'd like to see added or changed, **let us know!** Your feedback can help shape what's coming next.

## 📱 But Android users still have an advantage

While we're happy to finally bring PrintPriceTool to the web, the **Android app is still the better and more complete experience**.

If you have an Android phone, we strongly encourage you to install the mobile app. It's designed specifically for mobile use and offers the full PrintPriceTool experience right in your pocket.

The web version is great when you don't want to install an app — but the mobile app remains our recommended way to use PrintPriceTool on Android.
