# 🐧 ZgubaČasa 0.1.0 Canary for Linux Is Here!

We're excited to announce that the **first Linux desktop release of ZgubaČasa (version 0.1.0)** is now available! 🎉

This is an important milestone for the project, bringing ZgubaČasa to Linux desktop users for the first time.

## 💻 First Linux Release

The first Linux version is now available as a **Canary release**. This means it's an early version intended for testing and gathering feedback before further development.

You can download it here:

👉 **[Download ZgubaČasa for Linux](https://treved.dev/zgubacasa/download/linux)**

The desktop application is currently available in **Slovenian and English**.

## 🧪 Please Note: Canary Release

Since this is the very first release (**0.1.0 Canary**), it may contain bugs, unexpected behavior, or other issues.

The application is still under development, so things may not work perfectly yet. We encourage users who enjoy testing early software to give it a try!

## 💡 A New Feature: Contribute Your Own Facts!

The desktop version introduces an exciting new feature: **users can contribute additional fun facts to ZgubaČasa!**

This means the collection of interesting facts can grow with contributions from the community. We're looking forward to seeing what users come up with!

## 📱 What About the Mobile App?

The mobile version of ZgubaČasa is also **actively under development**!

We're working on bringing the app to mobile users, and it should become available to the wider public soon. Stay tuned for further announcements about its release!

## 🐛 Found a Bug? Let Us Know!

Your feedback is especially valuable during this early stage of development.

If you install the Canary release and encounter any bugs, errors, or unexpected behavior, please report them to:

📧 **support@treved.dev**

Please include a description of the problem and, if possible, the steps needed to reproduce it.

## 🚀 What's Next?

This is just the beginning of ZgubaČasa on desktop and mobile. We'll continue working on improvements, fixing reported issues, and developing the application further.

Thank you to everyone willing to try this early release and help make ZgubaČasa better!
